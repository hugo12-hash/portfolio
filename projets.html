Projets(01–04)

Quatre outils, tous nés d'une tâche que je faisais à la main sur mes dossiers. Chaque page présente le contexte, le problème, la solution et les technologies. Les données clients sont anonymisées.

  1. 01 Application web Plateforme d'automatisation comptable Une seule application web qui regroupe les automatisations du cabinet, pour que chaque collaborateur les utilise sans toucher au code. React, FastAPI, Python, Docker, Hugging Face Spaces
  2. 02 Outil juridique Assistant d'assemblées générales Un outil interne qui guide la préparation de l'assemblée générale ordinaire annuelle, de la collecte des informations jusqu'aux décisions à formaliser. React, FastAPI, Docker, OVH
  3. 03 Script d'automatisation Extraction des FEC en masse Un script qui récupère le fichier des écritures comptables de tout un portefeuille en une seule exécution, au lieu d'un export manuel par dossier. Python, API ACD i-Suite Expert
  4. 04 IA et veille Rapport financier quotidien Un rapport généré automatiquement chaque jour, où un modèle d'IA trie et analyse l'actualité économique. GitHub Actions, Python, Gemini
